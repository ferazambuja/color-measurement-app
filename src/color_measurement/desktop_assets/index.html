      Input requirements
      File inputs use the app’s typed Spectrum JSON: wavelengths, values, quantity and unit. The app checks declared units and grids. A named white is not an illuminant spectrum.

      How limits are used
      Each warning compares the CIE76 distance with the sum of the allowance and both bounds. The app uses your declarations; it does not estimate instrument uncertainty.

      Using Color Measurement
      

      

      Connect and set up
      1. Choose Connect instrument, then List connected instruments.
      2. Select your instrument, review its connection settings and effects, then choose Connect selected instrument.
      3. Choose Use for new batch, select the measurement mode and settings, then name the batch and choose a new save folder.
      4. Follow calibration and sample-placement instructions when prompted.
      Try Demo uses simulated instruments without connecting equipment. An existing instrument is available through New batch.
      

      Measure samples
      • The Measure button names the next sample.
      • Keep the default Sample #01 sequence, or enter a series such as White. Naming lets you keep exact names.
      • A successful reading advances the number and clears notes. A failed or cancelled reading keeps the target.
      • Repeat inspected repeats the selected reading and leaves the next sample prepared.
      

      Review your readings
      • Hover over a curve, point or row to highlight the same reading across the plots and table. Click a curve, point or sample name to inspect it and reveal its row. Hover keeps your selection and Follow latest unchanged.
      • Check rows to show their curves and points. Turn off Follow latest to keep inspecting an earlier reading.
      • Latest reading shows the last retained result, its approximate color, native units and available coordinates. It stays on that result while you inspect earlier rows.
      • Columns chooses the values shown in the table. Missing values show Unavailable.
      • Use a row's Edit button for its name and notes, or open Reading details for the complete record.
      

      Compare readings
      1. Inspect the reference reading.
      2. Open Analysis → Compare and choose Set inspected as reference.
      3. The table shows each reading’s change in Y and distance in u′v′. Check rows to overlay them in the plots.
      4. For Lab and ΔE00, choose and declare a white in Analysis → Color.
      The chosen reference and white stay with the batch.
      

      Use the plots
      • Each plot heading chooses Spectrum, Chromaticity, 3D, Chart guide or Spectral residuals. In View > Layout, Fit window shows two plots when there is room. One plot and Table only give more space to the view you need.
      • Each plot's Settings contains its display controls. View > Color previews sets shared RGB references and preview scale. Analysis beside the readings table opens comparison, color and activity tools.
      • In 3D, choose XYZ or CIELAB, then use Color gradient to see ideal RGB reference colors, or Colored outline for a clearer view of crowded points. Selecting CIELAB assumes D50 at white Y=100 in the reading’s units when no white is declared. Its legend names the assumption; Change white opens your white choices. Drag to rotate, scroll to zoom, or choose a camera view.
      • Use the table to select overlapping curves or points.
      

      Inspect and export saved data
      • Choose Batch > Open saved batch to inspect a batch folder or whole-batch MAT archive.
      • Batch > Open record file opens an original operation JSON/MAT or color observation JSON/MAT/CSV. Choose its contents explicitly.
      • Return to live restores your measurement workspace and pending edits. Reference and white changes during saved or imported review apply only to that review.
      • Batch > Export data saves all displayed or checked readings with their current analysis context. MAT appears when this runtime supports it.
      • Original record exports the imported source or one inspected color observation. SPECT requires qualified native data and a separately chosen JSON companion in the same folder.
      • If an export fails, Save retained export saves its original prepared snapshot to a new file.
      

      Automatic saving
      The batch saves its readings and updates MAT, CSV and supported TI3 files automatically. Use Batch > Automatic files to inspect each format.
      • Retry files saves pending outputs without measuring again.
      • Another folder moves recovery to a new destination.
      • Manual Export data creates a separate analysis snapshot.
      

      When saving needs attention
      • Read the save message and destination shown above the workspace.
      • Retry save saves the retained result again.
      • Another folder keeps the result and chooses a new destination.
      • Follow any cleanup instruction before measuring again.
      Finish batch ends acquisition and keeps readings available for inspection.

      ↓ / ↑ / ↕

      ◇ / ≈

      Understand the values and reference colors
      XYZ and spectra retain their reported quantities and units. x/y and u′/v′ are coordinates; black can have undefined coordinates. Lab and ΔE00 use your declared white. Spectral RMS and residuals require matching spectral grids and units.
      The spectral locus and ideal sRGB/Display P3 references help interpret the plots. Preview colors depend on the selected encoding and scale. Use numerical values and reference settings when reporting results.
      Scientific sources and rendering details
      Reference illustrations use the CIE 1931 2° color-matching functions, CIE 2019 dataset. The wavelength guide and chromaticity field use the app's shared RGB calculations; 3D reference colors use the same declared scale and white as their geometry.
