# Security reporting

This is beta software. Please identify the app
version or source commit and your operating system when reporting a problem.

Do not post vulnerability details, saved batches, serial numbers, credentials or
confidential files in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/ferazambuja/color-measurement-app/security/advisories/new)
to send a security report to the maintainer. If that form is unavailable, request
a private channel without disclosing the vulnerability or private data.
There is no security email address to infer from this document.

Ordinary software/platform reports use the issue templates. Retain original
records locally and share minimal redacted copies through an agreed channel.
