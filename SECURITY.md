# Security reporting

This is beta software with no published release yet. Please identify the app
version or source commit and your operating system when reporting a problem.

Do not post vulnerability details, saved batches, serial numbers, credentials or
confidential files in a public issue. No private vulnerability-reporting channel
is available yet. When repository hosting is established, use
its explicitly enabled private reporting channel. If none is offered, request
one from the maintainer without disclosing the vulnerability or private data.
There is no security email address to infer from this document.

Ordinary software/platform reports use the issue templates. Retain original
records locally and share minimal redacted copies through an agreed channel.
